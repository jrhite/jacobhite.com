Throughout the program the cohort builds a shared **Literacy Guide**, structured by
course module with terms listed alphabetically. Each cohort member defines the terms
for the module currently in session and contributes to the guide.

It covers Module 1 (Program Orientation), Module 2 (The Culture of Schooling),
Module 3 (The Learner and Learning in the Digital Age), Module 5 (Student
Assessments) and Module 6 (Planning and Preparation for Learning).

This page is the guide's one home on the site. Every module that contributes to it
points here, rather than each carrying its own copy of the link — one page to keep
current instead of six.
